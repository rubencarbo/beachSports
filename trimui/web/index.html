Beach Sports para TrimUI Smart Pro

Knulli + jsgamelauncher · versión __VER__

1. Prepara la consola

  1. START › Ajustes de red: activa el Wi-Fi y anota la dirección IP.
  2. En la misma pantalla, comprueba que SSH está activado.

2. Conéctate desde el ordenador

Abre una terminal (en Windows: PowerShell) y escribe, cambiando la IP por la de tu consola:

ssh root@192.168.1.50

Contraseña: linux (no se ve mientras la escribes). La primera vez responde yes.

3. Instala o actualiza el juego

Pega este comando en la terminal de la consola:

curl -fsSL __URL__/instalar.sh | bash

Si la consola no tiene jsgamelauncher, el instalador lo instala (5-10 minutos, no la apagues). Para actualizar el juego, repite este paso.

4. Juega

En la consola: START › Ajustes de juegos › Actualizar listas de juegos. Entra en JS Games › Beach Sports.

Cruceta / stickmoverse y apuntar
Agolpear · saque en dos toques (golpea en la zona verde)
Bsaltar
X / Ygolpe especial (barra llena)
Adelante + Agolpe plano · ataque
Atrás + Aglobo
STARTpausa
MENU + STARTsalir del juego

¿A y B al revés? AJUSTES › BOTONES A / B › CAMBIADOS.

Sin SSH

Si ya tienes jsgamelauncher (otro juego JS instalado), descarga beachsports-trimui.zip y copia la carpeta beachsports en /userdata/roms/jsgames/ de la SD.

Si algo falla

Activa AJUSTES › DIAGNÓSTICO y haz una foto de las líneas verdes. Registro por SSH:

tail -n 80 /userdata/system/logs/es_launch_stderr.log
